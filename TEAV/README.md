# TEAV — Research Antivirus

Учебный антивирус для Windows, реализующий три классических метода обнаружения угроз:
сигнатурный анализ, статический анализ PE-файлов и эвристический анализ.

---

## Требования

| Компонент | Версия |
|-----------|--------|
| Windows | 7 SP1 / 8 / 10 / 11 |
| .NET Framework | 4.7.2+ |
| .NET SDK | 8.0+ (только для сборки) |

Установить .NET SDK: https://dotnet.microsoft.com/download

---

## Сборка

```powershell
cd TEAV
dotnet build -c Release
```

Готовый EXE: `bin\Release\net472\TEAV.exe`

---

## База сигнатур

Файл `vvv.txt` должен лежать **рядом с папкой TEAV** (т.е. в `Desktop\vir\`).

Формат — одна запись на строку, допускается с номером через табуляцию:

```
1	d41d8cd98f00b204e9800998ecf8427e
2	e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
a7ffc6f8bf1ed76651c14756a061d662f580ff4de43b49fa82d80a4b80f8434a
```

Поддерживаемые алгоритмы: **MD5** (32 символа), **SHA1** (40), **SHA256** (64).

## Использование

```
TEAV.exe <путь> [опции]
```

### Аргументы

| Аргумент | Описание |
|----------|----------|
| `<путь>` | Файл или папка для сканирования (обязательный) |
| `-r` / `--recursive` | Рекурсивно сканировать подпапки |
| `-q` / `--quarantine` | Автоматически помещать угрозы в карантин |
| `-d` / `--delete` | Автоматически удалять угрозы |
| `-v` / `--verbose` | Подробный вывод |
| `--db <путь>` | Путь к базе сигнатур (по умолчанию `../vvv.txt`) |
| `--min-score <N>` | Минимальный балл эвристики для действия (по умолчанию 70) |

### Примеры

```powershell
# Проверить один файл
TEAV.exe C:\samples\suspicious.exe

# Сканировать папку рекурсивно
TEAV.exe C:\samples -r

# Сканировать и сразу помещать в карантин
TEAV.exe C:\samples -r -q

# Указать свою базу сигнатур
TEAV.exe C:\samples --db D:\hashes\malware_db.txt

# Понизить порог — репортить всё с баллом >= 30
TEAV.exe C:\samples -r --min-score 30
```

## Вердикты

| Вердикт | Условие |
|---------|---------|
| `CLEAN` | Score < 30 и нет сигнатуры |
| `POTENTIALLY UNWANTED` | Score 30–69 |
| `SUSPICIOUS` | Score 70–99 |
| `MALICIOUS` | Score ≥ 100 или совпадение по сигнатуре |

## Карантин

Карантин создаётся в папке `quarantine\` рядом с `TEAV\`.

Каждый файл хранится в двух артефактах:
- `имя_дата.quar` — XOR-зашифрованное тело файла (не может случайно запуститься)
- `имя_дата.meta` — JSON с исходным путём, хэшами, причиной детекции

При интерактивном режиме (без `-q` и `-d`) программа спросит для каждой угрозы:
```
Action? [Q]uarantine / [D]elete / [S]kip:
```

## Запуск в JetBrains Rider

1. `File → Open` → выбрать `TEAV.csproj`
2. `Run → Edit Configurations`
3. В поле **Program arguments** указать путь и опции, например:
   ```
   C:\samples -r --min-score 50
   ```
4. Нажать Run (▶)
